# WCAG 2.1 AA Accessibility Audit Plan

## Tools

- Accessibility Scanner
- Stark
- TalkBack
- VoiceOver

## Audit Checklist

- Color contrast
- Text scaling
- Screen-reader support
- Keyboard navigation
- Alternative text
- Touch-target sizing

## Process

1. Scan the application.
2. Identify accessibility issues.
3. Document findings.
4. Apply fixes.
5. Retest.
